> 面向 GalGame / Visual Novel 资源处理的 CG 与差分合成工具。

**GalGameCG** 是一个用于 GalGame CG / 人物差分合成的 Windows 工具，提供自动合成、半自动合成与手动调整等多种模式，主要用于处理 KRKR / PSB / PIMG 资源以及部分 Unity 游戏的差分资源。

## 🚀 快速开始

### 1. 解包 PIMG / PSB

部分 KRKR 引擎游戏会使用 `.pimg` 对 CG 资源进行封装，可以使用 **FreeMote** 中的 `PsbDecompile.exe` 解包。

1. 下载并解压 [FreeMote](https://github.com/UlyssesWu/FreeMote/releases)。
2. 找到 `PsbDecompile.exe`。
3. 将需要处理的 `.pimg` 文件拖到 `PsbDecompile.exe` 上。
4. 解包完成后，原目录通常会生成：
   - 与 PIMG 同名的资源文件夹；
   - `.json` 坐标文件；
   - `.resx.json` 文件。

其中：

- 资源文件夹：保存拆出的图片；
- `.json`：GalGameCG 自动合成所需的坐标信息；
- `.resx.json`：重新封包时可能会用到，如果确定不需要重新封包可以删除。

### 2. 使用 GalGameCG 自动合成

1. 从 [Releases](https://github.com/ex55kk/GalGameCG/releases/latest) 下载最新版 EXE。
2. 启动程序。
3. 打开 **工具 → 坐标差分自动合成**。
4. 点击 **添加坐标文件**。
5. 选择解包得到的 `.json` 文件，可一次添加多个。
6. 点击 **开始自动合成**。

对于大多数 PIMG CG，这就是最推荐的使用方式。

## 🛠️ 工具说明

### 坐标差分自动合成

主要用于多数 PIMG / PSB CG。程序会读取 JSON 中的图层尺寸、坐标、透明度以及分组关系，自动将背景和对应差分组合后导出。

### 坐标差分半自动合成

用于人物差分合成，目前主要支持部分解包后坐标文件为 TXT 的资源。需要手动确认背景、普通差分、背景差分和附加差分等类型。

### 差分手动合成

用于没有可用坐标文件的情况。可以手动调整差分的 X / Y 坐标进行合成，例如人物差分坐标被加密、缺失或格式无法解析时。

### 固定差分自动合成

适用于部分 Unity 游戏。某些游戏的 CG 差分使用固定坐标，只需要根据 CSV 等资源关系进行组合即可。

目前已知《苍之彼方的四重奏》一类资源可以使用这种思路处理。

### 分解差分半自动合成

用于“多个人物差分被放在一张大图里”的资源形式。程序可以进行分割并实时预览，但由于需要实时切割与渲染，在放大和调整差分位置时可能出现明显卡顿。

## 🎨 人物差分合成

人物差分比普通 CG 合成复杂一些。如果你只需要快速导出 CG，可以跳过这一节。

### 基本区域

坐标差分页面大致分为：

- **中间**：输出日志、预览、列表；
- **下方**：导出格式、导出全部坐标文件、导出当前页面、导出当前背景；
- **上方**：添加坐标文件、差分设置、画布尺寸等。

### 添加 TXT 坐标文件

点击 **添加坐标文件** 选择人物差分坐标文件，可一次添加多个。

如果坐标内容本身正确，但文件后缀不是 `.txt`，可以尝试修改扩展名；若直接打开出现乱码，也可以尝试更改编码，或直接交给程序读取。

### 背景

在坐标列表中找到人物的完整背景 / 身体图，将类型设置为 **背景**。

未勾选“开启”的项目在合成时会被跳过，因此遇到空白或无效图层时，可以直接关闭该图层。

### 普通差分

眼睛、眉毛、嘴巴等通常属于普通差分。程序会尝试根据名称自动识别类型，但自动识别并不保证完全正确，建议导出前检查一次。

### 背景差分

背景差分适合处理：

- 头发遮挡修复；
- 面部明暗变化；
- 不同服装对应的局部覆盖；
- 特定背景专用的修复层。

例如眼睛图层覆盖到刘海时，可以将头发局部图作为背景差分，在人物差分合成完成后再次覆盖到最外层。

#### 适用对象

可以指定背景差分只作用于特定：

- 普通差分；
- 背景。

例如角色存在“普通服装”和“刀服”两套头发修复差分时，可以分别指定适用背景，避免两套修复层同时叠加。

#### 单独背景差分

启用后，每个背景差分会单独生成一组结果，而不是全部叠加在一起。

例如存在 `A`、`B` 两个背景差分时，会分别导出：

```text
背景 + A
背景 + B
```

而不是默认叠加为 `背景 + A + B`。

### 附加差分

附加差分通常用于：

- 頬染 / 脸红；
- 流汗；
- 其他额外效果层。

可以为附加差分设置导出后缀，并指定适用对象。

#### 组合导出逻辑

假设有 `A`、`B` 两个附加差分，默认组合导出为：

```text
RAW
A
B
AB
```

如果有 `A`、`B`、`C`：

```text
RAW
A
B
C
AB
AC
BC
ABC
```

启用 **单独附加差分** 后，则只导出：

```text
RAW
A
B
C
```

为了避免组合数量爆炸，当附加差分数量超过 4 个时，程序会自动限制组合方式。

## 🖼️ 预览与导出

配置完成后，可以在右侧分别选择背景、普通差分和附加差分，并在中间区域预览最终效果。

### 画布尺寸

坐标文件里的原始分辨率通常是游戏内部画布尺寸，不一定适合作为最终导出尺寸。过大的画布会明显降低导出速度，因此可以手动调整画布大小，只需要保证人物完整位于画布内即可。

### 导出方式

支持：

- **导出全部坐标文件**：批量处理所有已添加 TXT；
- **导出当前页面**：处理当前 TXT 中的所有背景；
- **导出当前背景**：只导出当前选中的背景组合。

默认输出通常位于坐标文件同目录下的 `output` 文件夹。文件夹结构和文件名格式可以通过程序中的导出格式设置修改。

> 点击 **重置** 会清空当前页面设置；在正在导出时点击重置，也可以用于停止导出。

## 🧠 PIMG CG 合成原理

目前已发现的 PIMG JSON 坐标结构主要有两种。

### 1. Name 分组

JSON 最外层通常包含画布尺寸，例如：

```text
height
width
layers
```

`layers` 中每一项对应一个图片图层。CG 通常存在多个背景，可以根据 `name` 进行分组。

例如：

```text
Aa  → A 组背景
Ab  → A 组差分
Ac  → A 组差分

Ba  → B 组背景
Bb  → B 组差分
```

常见字段：

| 字段 | 含义 |
| --- | --- |
| `height` | 图层高度 |
| `width` | 图层宽度 |
| `layer_id` | 对应的图片 / 图层 ID |
| `left` | 图层相对背景的 X 位移 |
| `top` | 图层相对背景的 Y 位移 |
| `opacity` | 图层透明度 |

程序根据这些数据将图层绘制到对应位置即可完成 CG 合成。

### 2. Diff 分组

另一种结构不会再根据 `name` 的字母分组，而主要通过 `diff_id` 建立背景与差分的对应关系。

程序的基本判断逻辑：

1. 没有 `diff_id`，且尺寸与画布一致的图层 → 背景候选；
2. 存在 `diff_id` 的图层 → 差分；
3. `diff_id` 对应背景图层的 `layer_id`；
4. 根据坐标与透明度将差分覆盖到对应背景。

## ⚠️ 已知限制

- 某些游戏会加密或修改坐标文件格式，无法保证全部兼容；
- 自动识别人物差分类型可能出现误判，需要手动检查；
- 分解差分模式在实时切割和放大预览时可能较卡；
- 不同厂商、不同版本引擎的 PSB / PIMG 结构可能存在差异；
- 坐标差分半自动合成功能仍在完善中。

如果发现无法正常处理的资源格式，欢迎提交 Issue，并尽量附上经过脱敏的坐标结构、错误信息和复现方式。
